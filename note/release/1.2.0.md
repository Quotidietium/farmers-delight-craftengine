# 1.2.0 — REF 源码对照移植：mod 精确机制 + 原版作物上沃土 + REF 模型对齐

> 移植方法：反编译 `REF/papersdelight.jar`（无加密早期版）作为 CE/Paper 实现方法参考；
> 一切机制规格以本仓库 mod 源码（farmers-delight-fabric 1.20.1-1.4.3）为准。

## 机制修复（mod 违规，均以 mod 源码钉死）

- **堆肥**：对齐 mod `OrganicCompostBlock.scheduledTick` —— 3×3×3 扫描、每激活剂 +0.02、
  天光>12 +0.1（否则 +0.05）、水 +0.1，随机刻节奏（每游戏刻 3/4096）；满级同概率转沃土。
  （原实现 0.0125 体系，约快 137 倍）
- **砧板**：时运改用 FORTUNE（误用 LOOTING）；产物向朝向**左侧**弹射
  （`rotateYCounterclockwise`，偏移 0.2、速度 0.2、无垂直分量）；补剪刀音效分支。
- **煎锅（放置）**：整叠放入逐个烹饪（原来完成即清空整叠只出一份）；火焰附加取自
  **煎锅本体**（放置时序列化保存，破坏还原附魔）；失热 -2/tick 衰减；产物向右侧
  弹射（速度 0.08h/0.25y）；蒸汽/火续粒子。
- **厨锅**：同类型餐可续煮（餐盘槽同类可叠加继续烹饪）；食材容器残留弹出
  （桶/汤碗/药水瓶 + milk_bottle→玻璃瓶、tomato_sauce→碗）；容器需求回退到成品自身
  残留物；漏斗三面交互（上方投料、侧向投器皿、下方取成品，1 个/脉冲）；
  破坏时餐食随锅物品 PDC 携带（CopyMeal）+ 经验球结算（小数概率进位）+ 放置还原；
  经验结算统一 mod 公式。
- **作物生长**：全部改写为 mod 精确数学 —— 原版 CropBlock 公式
  （3×3 耕地环肥力 湿度>0?3:1 除环心外 ÷4、同作物十字成对或任一对角 ÷2、
  1/(floor(25/f)+1) 掷骰、光照≥9），节奏为原版随机刻（3/4096 每刻）。
  沃土耕地**不加肥力**（mod 设计：其收益是 20% 自动骨粉 +2~5 龄）。
- **收获/骨粉数值**：卷心菜/洋葱右键采收移除（mod 1.4.3 无此功能，破坏掉落对齐
  战利品表：成熟卷心菜+二项(3+时运,4/7)种子）；番茄藤 max 3、右键采 1-2 个+5% 烂番茄
  并重置 age 0 + 采摘音效；骨粉增量 卷心菜/洋葱 +2-5、番茄藤 +1-2、番茄苗 +1-4
  溢出变藤（藤龄=g-4）、稻 +1-4 溢出成稻穗；稻下段 = 自有路径（上方光照≥6、
  1/3 门、阈值 3），稻穗 = 原版公式基线 f=1；番茄攀绳 30%/随机刻、限高 3。
- **稻草注入**：刀割成熟小麦必得 1 稻草；草/高草 20%（对齐 mod 战利品注入）。

## 新功能（mod 特性，借 REF 实现方法）

- **原版作物种沃土耕地**（mod mixin 特性的 CE 等价实现）：
  - 新 CE 行为 `farmersdelight:crop`（插件注册）：原版精确生长公式 + 骨粉 +2-5
    （甜菜型 1/3 随机刻跳过 + 骨粉 0-1）+ canSurvive 土壤表 + BlockGrowEvent 管线。
  - 新 CE 行为 `farmersdelight:rich_farmland`：沃土耕地湿度 0-7 模拟
    （9×2×9 水域/降雨回满、干旱递减）、满湿 20% 自动骨粉上方作物（+2-5 龄 + 幸运粒子）、
    失撑转回沃土、免踩踏。
  - 4 种高级作物（小麦/胡萝卜/马铃薯/甜菜根）复用原版作物方块状态做外观（零状态预算），
    种子物品重定向（原版耕地上回落原版种植）；掉落对齐原版战利品表
    （二项 3+时运 p=4/7、2% 毒马铃薯）。
- **厨锅 GUI**：22 段进度条（paper CMD 325001..325022，REF gui 资产 25 模型/31 贴图
  经 ce_gen 新模块 vendored）、热源指示、mod 空槽贴图填充。
- **厨锅配方书**：列表（45/页分页）+ 详情双视图，锅界面按钮进入、可返回锅
  （保留打开会话）。

## 模型对齐（按 REF CE 包 v0.10.6）

- REF 编辑过的 76 个模型 + 39 张贴图 vendor 进 `tools/ce_gen/assets_ref`，
  生成时覆盖 mod 原始资产（盛宴剩余盘/新美术、托架、榻榻米配对纹理、
  沃土耕地自定义模板、标准 display parent 等）；REF 的竹篮重制（引用其自创内容）
  按仲裁规则排除。
- 沃土耕地破坏掉沃土（mod 对齐，原掉自身）。
