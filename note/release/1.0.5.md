# 1.0.5 — 烹饪锅自定义 GUI 锚定 CE 原生打开事件

## 架构变更（消除对未测事件路由的依赖）
烹饪锅专用 GUI 的打开不再依赖 CE FurnitureInteractEvent / Bukkit PlayerInteractEntityEvent 路由：
1. 右键空手锅 → **CE 原生 simple_storage GUI 先打开**（CE 已验证管线，与官方家具同链路）
2. 插件在 InventoryOpenEvent(MONITOR) 检测到锅的原生存储界面（WorldlyContainerHolder@锅位）→
   **下一 tick 替换为专用布局**（同一 CE 库存：6 输入+餐盘+碗+输出），日志输出 `[GUI] pot layout swapped`
3. 手持容器取餐/潜行切换支撑仍走事件路径（取消式，不涉及 GUI 打开）

即：专用 GUI 的触发链 = CE 原生打开事件（保证开）→ 1 tick 换肤（纯 Bukkit close/open）。
即使换肤一步失败，玩家仍有完整可用的 9 格 CE 原生界面（物品照常烹饪）。
