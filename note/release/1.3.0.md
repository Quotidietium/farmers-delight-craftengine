# 1.3.0 — 烹饪锅架构迁移：家具 → 真实 CE 方块

## 迁移内容
- ce_gen：锅从 furniture.yml 移至 blocks.yml——复用 mod blockstate 的
  facing×support 外观组合（none/tray/handle 全保留）、lantern 音效家族
  （hardness 0.5/resistance 6.0，mod 原值）、loot 掉锅本体；物品转 block_item。
- 新 CE 行为 `farmersdelight:cooking_pot`：**mod 比较器公式**
  `floor(填充率×14)+1`（9 槽填充率，MathUtils.calcRedstoneFromItemHandler 同式）。
- 插件：potIndex 区块索引 + tickPotBlock（BlockStore 区块 PDC 存储，键 inv/cook/
  cooktotal/container/exp）；漏斗三面交互、取餐/容器装碗、残留弹出、经验结算、
  专用 GUI（CookingPotBlockGui，槽位布局与家具版一致）全部接通。
- **CopyMeal 保留**：破坏掉 8 槽+经验球，餐食随锅物品 PDC 携带（含 lore），
  重放置还原；潜行空手循环 support 变体。

## 兼容性
- 存量世界已放置的家具锅走 legacy 家具路径继续工作（双路径共存）；
  新放置的锅一律为真实方块。行为/存储格式均无破坏性变更。

## 验证
- 全新世界冒烟：60 对象放置 0 失败、potIndex 注册、ticker 有负载、0 错误；
  包生成/行为解析全绿。
