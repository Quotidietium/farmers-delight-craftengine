# 1.3.1 — 盛宴/派比较器与架构收尾

## 派 ×3（apple_pie / sweet_berry_cheesecake / chocolate_pie）
- 已是 CE 方块，补 `farmersdelight:comparator_signal`：信号 = `3 − bites`（mod PieBlock）。

## 盛宴 ×5（家具 → 真实 CE 方块）
- ce_gen：facing×servings 外观复用 mod blockstate，**放置即满份**（4/8，mod
  getDefaultState 语义）；comparator = servings（mod FeastBlock）；wool 音效家族
  （mod WHITE_WOOL/PUMPKIN/CAKE 近似）。
- 插件：右键取食（手持碗、每份食物、RiceRoll 按份数表 kelp_roll_slice/salmon_roll/
  cod_roll）、空盘木头破坏音+掉落、stuffed_pumpkin 末份消失（hasLeftovers=false）、
  破坏掉落（满份=盛宴自身，动过=碗+骨粉，mod loot 表）、放置进度触发。
- 存量家具盛宴走 legacy 家具路径兼容。

## 比较器矩阵（mod 全 6 类闭合）
锅=填充率、篮/橱柜=CE 原生存储、堆肥=8−阶段、盛宴=份数、派=3−bites。
