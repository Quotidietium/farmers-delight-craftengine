# 1.4.6 — UX 轮 5：灶台失败原因提示 + 玩法速查命令

### 灶台放置失败原因提示（UX 叠加，mod 为静默失败）

- `/fd` 无参数帮助与 Tab 补全同步更新为 `help | version | status | guide`。
