# 1.0.2 — 家具客户端渲染修复（bench 模式对齐）

## 问题
客户端上煎锅、砧板等家具放置后不可见（透明/不渲染），服务端实体与生成的资源包均验证正常。

## 修复（对齐 CE 官方 bench 的已验证渲染模式）
1. **默认变体直接渲染家具自身物品**（砧板/锅/煎锅/绳子/安全网/地毯/榻榻米/盛宴满份）——与 CE 默认家具 bench 完全相同的展示链路（element item = furniture item → item model → block 模型），消除内部物品间接层
2. **变体视觉物品（锅托架/煎锅托架/盛宴各份数/告示牌 34 色/榻榻米配对）改用自包含模型**：62 个新生成的 parent-free 模型（`models/item/internal/`），不依赖任何父模型解析——消除客户端父链解析失败的最后一类风险
3. 资源包自动再生（1.0.1 引入）+ 版本 1.0.2 强制所有环境刷新

## 升级注意
替换为 `farmers-delight-papo-1.0.2.jar` 重启；若客户端仍显示异常，在客户端删除服务器的旧资源包缓存后重进。

## 验证
- 冒烟：0 错误 0 警告，RP 自动再生
- RP 结构审计：220 个 items/ 定义全链路（定义→模型→父链→面贴图映射→PNG）0 问题
- 62 个自包含内部模型确认 parent-free 且含 elements
