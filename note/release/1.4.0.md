# 1.4.0 — 背刺改数据包附魔（附魔台获取，偏差⑦闭合）

## 变更
- 背刺从 Paper RegistryEvent 插件注册改为 **1.21 数据包附魔**
  （`data/farmersdelight/enchantment/backstabbing.json`，与捆绑进度数据包同包）：
  - supported_items / primary_items = CE 刀具底层材质
    （flint / iron_nugget / gold_nugget / diamond / netherite_scrap）
  - min/max cost 与 anvil cost 按 mod（15+9×级 / 65 / 4）
  - max_level 3、weight 10、mainhand
- 数据包附魔是原版附魔台枚举的注册表条目——**附魔台候选确定性出现**（不再依赖
  插件注册与材质匹配的间接路径）
- 效果计算不变：插件 EntityDamageByEntityEvent 按 mod 公式
  `×(1.2+0.2×等级)` + 暴击音 + 击退修正

## 兼容性
- Bukkit `Enchantment.getByKey(farmersdelight:backstabbing)` 对数据包附魔照常解析，
  已有带背刺附魔的物品无损。

## 验证
- 冒烟：数据包加载 0 错误，启动日志 `Backstabbing datapack enchantment: resolved
  (farmersdelight:backstabbing)`，进度 22/22。
