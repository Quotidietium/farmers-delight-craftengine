# 1.4.3 — 刀具小功能补全：雕刻南瓜 + 蜡烛蛋糕刀切

## 新增（mod KnifeItem / KnivesEventListener 移植）
- **雕刻南瓜**：手持刀具右键原版南瓜 → 雕成南瓜灯（朝向=点击面；顶/底面点击时
  取玩家朝向反向）+ 雕刻面弹出 4 南瓜种子 + carve 音效 + 刀具耐久 -1。
- **蜡烛蛋糕刀切**：手持刀具右键 17 种蜡烛蛋糕 → 弹出蜡烛 + 1 蛋糕片 +
  留下 bites=1 的普通蛋糕（mod KnivesEventListener 逻辑）+ wool_break 音效。

## 验证
- 冒烟：0 错误、进度 22/22、Boot 全绿。
- 至此 mod item/event 层全部小功能（雕刻/切蛋糕/切蜡烛蛋糕/切派/鹦鹉驯服/喂食/
  投掷/搜刮/钟绳）均已覆盖。
