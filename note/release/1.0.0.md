# 1.0.0 — Farmer's Delight Papo 插件移植版

> 发布日期：2026-08-18
> 产物：`papo-plugin/build/libs/farmers-delight-papo-1.0.0.jar`

## 概述

将 Farmer's Delight Fabric 模组（1.20.1-1.4.3，173 Java 文件/1.4 万行）完整重写为
Papo（Paper 1.21.11）插件，材质/模型/音效/语言全部由 CraftEngine 26.7.4 托管。

## 主要内容

- **CraftEngine 资源包生成器**（`tools/ce_gen`，9 个 Python 模块）：
  - 158 物品 / 55 CE 方块 / 35 家具 / 148 CE 配方 / 14 音效 / 30 语言
  - 通用 blockstate→CE states/variants 转换器（含 auto_state 容量预算分配）
  - FD 物品标签声明 + c: 标签递归展开
- **插件**（26 个 Java 类）：
  - Bootstrap 注册背刺附魔（Paper RegistryEvents）
  - PackInstaller 自动部署 CE 包 + reload 钩子
  - 砧板/烹饪锅（GUI）/炉灶/煎锅/篮子/橱柜 全功能
  - 作物生长/沃土/堆肥/野生生成（GameTicker 0.5s 心跳 + 区块 PDC 索引）
  - 舒适/滋养服务端模拟、食物效果、刀/背刺、投掷、动物、交易、战利品
- **文档**：`note/port/README.md`（架构 + 功能对照审计 + 8 项平台限制偏差表）
