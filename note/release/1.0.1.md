# 1.0.1 — 家具渲染修复 + 农夫乐事大分类

## 修复

### 家具放置后不显示（关键）
- 根因：CE 的普通配置重载不触发 `generateResourcePack()`；PackInstaller 安装/更新内容后资源包从未再生，客户端持有的定义陈旧 → 家具模型无法解析 → 隐形（服务端实体正常，已实证）
- 修复：`reloadContent()` 在配置重载成功后自动 `generateResourcePack() + uploadResourcePack()`
- 版本号升至 1.0.1 强制所有已部署环境重装并触发新管线

### 新增
- 顶级「农夫乐事」分类（en/zh_cn/zh_tw）嵌套 7 个子分类
- `/fdplace` 控制台诊断命令（放置家具并回显实体）

## 验证
- 冒烟：0 错误 0 警告；资源包随安装自动再生（1541 条目 / 76 内部展示定义 / 339 贴图）
