# 1.4.5 — UX 轮 3+4：投料路由全覆盖 + 完成反馈 + 命令补全

## 交互优化

### 烹饪锅 GUI：Shift 快速投料（物品锅 + 方块锅）
- 玩家背包内 Shift 点击食材/碗，自动路由进锅：
  - 碗 → 容器槽（仅当容器槽为空）
  - 其他食材 → 第一个空闲原料槽
- 路由失败（槽全满）时物品留在背包不动。
- 两套锅 GUI（furniture 物品锅 / CE 方块锅）行为一致。

### 烹饪完成音效（UX 叠加，mod 本身静默）
- 锅烹饪完成：`entity.experience_orb.pickup`（0.7 音量）——附近玩家不开 GUI 也能知道饭好了。
- 灶台烤制完成弹出食物：`entity.item.pickup`（0.5 音量 / 0.9 音调）。
- mod 规格为静默完成（已核对 CookingPotBlockEntity / StoveBlockEntity 均无音效）；此项为用户明确要求的 UX 叠加，不改变机制。

### 砧板取回音效
- 空手取回砧板上的食材时播放 `block.wood.hit`（0.25 音量 / 0.5 音调）。
- 对齐 mod 规格：`CuttingBoardBlock.pullOutItem` 的取物音效。

### /farmersdelight 命令 Tab 补全
- `/fd <Tab>` 提示 `help / version / status`，前缀过滤。
