# 1.0.3 — 功能方块 GUI 改用 CraftEngine 原生实现

## 问题
右键功能方块（橱柜/篮子/烹饪锅等）无 GUI 显示。

## 修复（按用户要求依靠 CraftEngine API）
1. **橱柜（10 种）+ 篮子 → CE 原生 `simple_storage_block` 行为**：
   - 右键 GUI 由 CE 自己的管线打开（ItemEventListener → useWithoutItem → BukkitInventory.open + OpenScreenPacket，与其官方家具同一套已验证链路）
   - 数据持久化在 CE 方块实体（区块 PDC craftengine:chunk_data），破坏时 CE 自动掉落内容物
   - 橱柜 `open` 方块属性由 CE 自动切换（开门动画）；篮子支持比较器信号与漏斗进出（mod 一致）
   - 篮子吸取改为向 CE 容器插入（经 BukkitAdaptor→CEWorld→BlockEntity→SimpleStorageBlockEntityController.inventory()）
2. **家具双路径交互兜底**：除 CE 的 FurnitureInteractEvent（包级监听）外，新增 Bukkit PlayerInteractEntityEvent 路径
   （经 CraftEngineFurniture.getLoadedFurnitureByCollider 反查家具），200ms 去重。烹饪锅/砧板/煎锅/绳子/盛宴/告示牌
   的交互在任一路径可用时都能触达——自定义 GUI 打开不再单点依赖 CE 包监听器。
3. 移除了旧的自定义 ContainerBlockGui 路径（橱柜/篮子）；烹饪锅保留专用槽位 GUI（6 输入+餐盘+碗+输出）。

## 实时验证（Papo 0.32.1 + CE 26.7.4）
- `fdplace block:oak_cabinet` → 放置成功 + **CE 存储实体 27 格创建** ✓
- `fdplace block:basket` → 放置成功 + **CE 存储实体 27 格创建** ✓
- 冒烟 0 错误 0 警告；版本 1.0.3 强制刷新
