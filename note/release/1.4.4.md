# 1.4.4 — BUG 修复：炉灶放物 / 砧板切物放刀

## 炉灶放不了东西（修复）
- 根因：交互实现错误地要求炉灶**已点燃**才允许放食物——mod 规格是未点燃也可
  放上烤架（点燃后自动开始烹饪），且顺序为「先查营火配方 → 无配方才尝试熄灭」。
- 修复：放食物移除点燃要求（保留上方遮挡检查，mod isStoveBlockedAbove）；
  熄灭（铲/水桶）移到放食物判定之后，与 mod 顺序一致。

## 砧板把小刀放上去（修复）
- 场景：空砧板手持小刀右键 → 刀被当食材放上板；板上物品无对应切割配方且
  潜行时刀也会被放上板。
- 修复：
  - 空板 + 手持小刀 → 不再放置，actionbar 提示「手持食材放上砧板，再用小刀切割」
    （潜行仍可放置，用于 mod 的刀具雕刻展示）。
  - 板上有物品 + 手持小刀但无匹配配方 → 不再放刀，actionbar 提示
    「该物品无法用小刀切割」。
  - 有配方时正常切割不受影响。

## 验证
- 构建通过；冒烟 0 错误、进度 22/22。
