# 1.4.4 — BUG 修复：炉灶放物 / 砧板切物放刀

## 炉灶放不了东西（修复）
- 根因：交互实现错误地要求炉灶**已点燃**才允许放食物——mod 规格是未点燃也可
  放上烤架（点燃后自动开始烹饪），且顺序为「先查营火配方 → 无配方才尝试熄灭」。
- 修复：放食物移除点燃要求（保留上方遮挡检查，mod isStoveBlockedAbove）；
  熄灭（铲/水桶）移到放食物判定之后，与 mod 顺序一致。

## 砧板把小刀放上去（修复）
- 场景：空砧板手持小刀右键 → 刀被当食材放上板；板上物品无对应切割配方且
  潜行时刀也会被放上板。
- 修复：
  - 空板 + 手持小刀 → 不再放置，actionbar 提示「手持食材放上砧板，再用小刀切割」
    （潜行仍可放置，用于 mod 的刀具雕刻展示）。
  - 板上有物品 + 手持小刀但无匹配配方 → 不再放刀，actionbar 提示
    「该物品无法用小刀切割」。
  - 有配方时正常切割不受影响。

## 另修（1.4.3 真实运行崩溃）
- 方块锅 facing 属性读取 ClassCastException：CE 的 facing 属性值为 Direction 类型，
  不能按 String 泛型读取——新增类型安全的 `GameTicker.getPropString`（任意属性
  Object→小写字符串），tickPotBlock / 灶台放置 / 篮子放置三处统一换用。
- `BlockStore.getInt` 新增带默认值重载，方块锅 cook/cooktotal 字段缺失时按 0 处理
  （此前新放置的锅每 tick 抛 NullPointerException）。

## 验证
- 构建 + 全新世界冒烟：bench load 60 对象放置 0 失败、0 异常
  （ClassCastException / NPE 均为 0）、进度 22/22。
