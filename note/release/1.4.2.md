# 1.4.2 — 修复：背刺数据包附魔文件缺失（1.4.1 回归）

## 问题
1.4.1 构建中 `backstabbing.json`（数据包附魔定义）被误删——数据包注册表缺条目
（registry size=43、无 farmersdelight:backstabbing），且移除插件注册后
`Enchantment.getByKey` 无法解析数据包附魔 → **背刺完全失效**。

## 修复
1. 恢复 `backstabbing.json`（registry size=44、条目注册实证）。
2. 附魔解析改走 Paper RegistryAccess 镜像（`Enchantment.getByKey` 不覆盖数据包
   附魔——旧 API 陷阱），PlayerListener 背刺等级读取同步修复。
3. 启动新增 `canEnchantItem` 探针：**5 种刀具底层材质（flint/iron_nugget/
   gold_nugget/diamond/netherite_scrap）全部 true**——该函数即原版附魔台
   offer 构建的 supported_items 判定，背刺候选确定性出现。

## 建议
1.4.1 请勿使用；1.4.0 用户升级到 1.4.2（1.4.0 的效果监听在 1.4.2 起改走
RegistryAccess，存档附魔无损）。
