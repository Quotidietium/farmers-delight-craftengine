# 1.4.1 — 高级作物补全：南瓜/西瓜茎 + 火炬花/瓶子草（mod mixin 功能全覆盖）

## 新增（mod「任意作物可种沃土」mixin 的剩余覆盖）
- **南瓜/西瓜茎**（advanced_pumpkin_stem / advanced_melon_stem）：
  CE 内建 stem_block 行为接管生长与结瓜（南瓜/西瓜本体），fruit_bottom_blocks
  含沃土耕地/沃土（13 种，REF 同表）；attached 方块×2（4 向外观）。
  种子重定向（原版耕地上回落原版种植）。
- **火炬花**（advanced_torchflower_crop）：age 0-2，成熟外观为火炬花方块本体
  （vanilla getStateForAge）；1/3 随机刻门（vanilla TorchflowerCropBlock）、
  骨粉固定 +1。
- **瓶子草**（advanced_pitcher_crop）：age 0-4（单格近似，REF 同构）、骨粉固定 +1
  （vanilla PitcherCropBlock.performBonemeal）。
- 掉落：stem 破坏 = 种子 × binomial(3+时运, 4/7)（原版 loot）；torchflower
  成熟掉花/未熟掉种子；pitcher 按年龄 1-3 荚（近似原版 alternatives）。

## 行为增强
- `farmersdelight:crop` 行为新增 `bone_meal_bonus: "min-max"` 参数
  （默认 2-5；子类覆盖 torchflower/pitcher 固定 1）。

- 全新世界冒烟：blocks 91→97（+6）、0 错误、进度 22/22。
- mod mixin「任意作物可种沃土」至此全覆盖（8/8 种）。
